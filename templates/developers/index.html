Incredibles API · v1.0

Build apps with music & quotes.

REST API for developers. Fetch published music and quotes from Incredibles using a simple Bearer token.

https://dutoza-api.onrender.com

Getting Started

Three steps to start calling the API.

1

Get an API key

Register as a developer and create a key from the dashboard.

2

Authenticate

Send the key in the Authorization: Bearer header.

3

Call endpoints

Request /api/music or /api/quotes and use the JSON response.

Authentication

Protected endpoints need a valid API key.

Header
Authorization: Bearer dutoza_your_api_key_here
Important: Keep your API key private. Do not put it in public GitHub repos or client-side browser code.

Music API

List and fetch published songs (title, artist, audio, cover, genre…).

GET /api/music

Returns the published music library (paginated / searchable depending on query params).

curl https://dutoza-api.onrender.com/api/music \ -H "Authorization: Bearer YOUR_API_KEY"

Rate Limits

      
Default limits protect the API for everyone.

      

        
Default per API key

        
60 / min

        

          If you exceed the limit you receive 429 Too Many Requests.
          Contact support if you need a higher limit.

Security

      
Best practices when integrating the API.

      

        

          
Do

          
Store keys in server env vars. Use HTTPS only. Rotate keys if leaked.

        

        

          
Don’t

          
Hardcode keys in mobile apps or public frontend JS. Don’t share keys between teams without tracking.
