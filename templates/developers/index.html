DUTOZA API · VERSION 1.0.0

Build powerful apps with Incredibles API.

Access music, quotes and other Dutoza services through a simple REST API built for developers.

https://dutoza.com/api

Getting Started

Start using Incredibles API in three simple steps.

1

Get an API key

Create or receive an API key from the Dutoza developer system.

2

Authenticate

Send the API key using the Authorization Bearer header.

3

Make requests

Call the API endpoints and process the JSON responses.

Authentication

Protected endpoints require a valid Incredibles API key.

Authorization
Authorization: Bearer YOUR_API_KEY
Keep your API key private. Never place a private key in public GitHub repositories or client-side code.

Music API

Access published music and music statistics.

GET/api/music

Returns the published music library.

curl https://dutoza.com/api/music \ -H "Authorization: Bearer YOUR_API_KEY"
Try API 











GET/api/music/{id}




Returns one published song.


GET /api/music/1



Try API



















POST/api/music/{id}/play




Registers a play for a published song.


POST /api/music/1/play









POST/api/music/{id}/download




Registers a download and returns the available audio URL.


POST /api/music/1/download












Quotes API

Rate Limits

requests per 60 seconds

Security


Follow these practices when integrating Incredibles API.




Protect API keys
Store private keys on your backend or secure environment variables.


Use HTTPS
Production API communication should use encrypted HTTPS connections.


Rotate exposed keys
Disable a key immediately if it becomes publicly exposed.
